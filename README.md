Docupilot is a document generation and automation platform with a REST API for creating PDFs, Word documents, PowerPoint presentations, and Excel files from templates using dynamic data merge and workflow automation. The API follows the OpenAPI Specification and supports integration with CRMs, HR systems, form tools, and third-party services via Zapier, Make, and native webhooks.

**Areas:** Document Generation · PDF Generation · Document Automation · Template Engine · E-Signature · Workflow Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Docupilot: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
